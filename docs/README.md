# 文档导航

phixlin-flow 的文档面向使用简体中文的用户和贡献者。代码中的字段名、命令、状态值、错误码和 Schema 标识是稳定接口，文档中保留英文原文；解释、决策和操作说明尽量使用简体中文。

## 从哪里开始

- [实现路线图](implementation-roadmap.md)：了解里程碑、当前进度和验收标准。
- [运行时设计](runtime-design.md)：了解状态机、阶段循环、交接和恢复边界。
- [CLI 契约](contracts/cli-v1.md)：查阅命令、参数和 change 目录约定。
- [状态协议](contracts/state-v1.md)：查阅状态字段、不变量和恢复依据。
- [CAS 提交协议](contracts/cas-v1.md)：查阅并发写入、原子替换和错误处理。
- [决策记录](decisions/README.md)：了解已经冻结的设计选择及其后果。

## 贡献文档的约定

新增或修改文档时，优先使用简体中文说明；协议中的机器可读标识不要翻译。涉及行为、格式或接口的改动，应在同一提交中更新相关文档和测试。
